MARKETMATH — START HERE
=======================

This is a static English-language website for craft-fair and handmade-product sellers.
It uses HTML, CSS, and JavaScript only. No server, build step, database, or paid API is required.

WHAT'S INCLUDED
- index.html: landing page and event profit planner
- product-pricing.html: handmade product pricing calculator
- break-even.html: craft fair break-even calculator
- about.html, privacy.html, terms.html, contact.html
- assets/styles.css: responsive design
- assets/app.js: calculations, copy buttons, local save
- robots.txt and sitemap.xml.template

BEFORE PUBLISHING — REQUIRED
1. Search all files for YOUR-DOMAIN.example and replace it with your real public URL.
   Canonical links should match the URL where each page will actually live.
2. In contact.html, replace REPLACE-WITH-YOUR-EMAIL@example.com with an email you control.
3. Review privacy.html and terms.html. They are starter text, not legal advice. Update them for your host, audience, and any analytics/ads you enable.
4. Test every calculator on desktop and mobile.
5. Rename sitemap.xml.template to sitemap.xml, replace the example domain, and add a Sitemap line in robots.txt.
6. Only add your official ad network script after your account/site is approved. Search for "AD SLOT" in the HTML files.
7. Do not encourage visitors to click ads. Keep ad placements distinct from buttons, calculator inputs, and navigation.

GITHUB PAGES (free static hosting)
1. Create a new public repository on GitHub.
2. Upload the CONTENTS of this folder (not the outer folder itself).
3. In the repository, open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
5. Wait for GitHub Pages to publish. Your URL will look like https://USERNAME.github.io/REPOSITORY/.
6. If using a project URL, replace canonical URLs with the exact project URL + each page path. Ensure sitemap URLs use the same base path.
7. Open every page directly to verify it loads. If you later use a custom domain, update canonical links, sitemap, and DNS/Pages settings.

SEO CHECKLIST
- Verify the site in Google Search Console.
- Submit your sitemap after deployment.
- Request indexing for the homepage and the two calculator pages.
- Write additional genuinely useful, original pages only when you can add value beyond the calculators.
- Use Search Console performance data to see which queries generate impressions and improve pages accordingly.
- No indexing method guarantees ranking or traffic. Do not generate lots of thin pages just to target keywords.

ADVERTISING
- This package does NOT contain an ad network script, publisher ID, or ad unit ID.
- Insert the code supplied by your approved ad provider in the marked AD SLOT locations.
- Check the provider's country, identity, age, payment, consent, and site approval requirements before relying on ad revenue.
- Ads may reduce usability if intrusive. Keep them separate from interactive controls.
- A visible ad is not evidence of meaningful traffic or earnings.

IMPORTANT LIMITATIONS
- The niche was chosen as a focused starting hypothesis, not because keyword volume or low competition has been proven. Validate keywords and demand with real Search Console/keyword data.
- The calculators use USD and the fee rates entered by the visitor. They do not predict event traffic or sales.
- Saved event plan values are stored in the user's browser local storage.
